Reimport All Calendars

Deletes all existing calendar entries for every shul that has a calendar URL configured, then fetches and re-classifies everything from scratch. Use this to fix stale data — for example, entries that show "Shkiya:" instead of "Plag:" because they were imported before the classifier was improved.

  • Applies to all orgs with a calendar URL (ignores useScrapedCalendar flag)
  • Re-runs the full classification pipeline on every event
  • Replaces stale imported materialized rows as part of the import
  • Live schedule updates for dates inside the rolling window
Safe
Rematerialize All

Triggers a full rebuild of the materialized calendar_events table from Minyan rules and imported calendar entries. This is the same job that runs automatically every Sunday at 2 AM. Use this for manual repair/backfill or to refresh the rolling schedule window on demand.

  • Deletes and rebuilds all RULES-sourced events
  • Preserves IMPORTED and MANUAL events
  • Covers the rolling 11-week window
Safe
Geocode All Shuls

Looks up GPS coordinates for shuls that are missing latitude/longitude values using the configured Mapbox Geocoding API. Existing coordinates are skipped unless you choose to force a full refresh.

  • Backfills missing coordinates for all shuls
  • Can optionally refresh shuls that already have coordinates
  • Useful after address cleanup or Mapbox token/config changes
